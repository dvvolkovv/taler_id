# Подключите AI-ассистента к Taler ID

> Контент страницы для лендинга. Выкатывается на id.taler.tirol / talerid.io вместе с
> релизом MCP на TEST/PROD; до этого фича доступна только на DEV (staging).

---

## Ваш AI-ассистент теперь умеет работать с Taler ID

Подключите Claude, ChatGPT или любого другого AI-ассистента к своему аккаунту Taler ID —
и управляйте календарём, заметками и сообщениями голосом или текстом:

- 🗓 **«Поставь встречу с Иваном завтра в 15:00 и напомни за полчаса»**
- 📝 **«Запиши в заметки: обсудить бюджет на Q3»**
- 💬 **«Что мне ответила Анна? Напиши ей, что я согласен»**

## Как подключить (на примере Claude)

1. Откройте **claude.ai → Settings → Connectors → Add custom connector**
   (или Claude Desktop → Settings → Connectors).
2. Вставьте адрес:
   ```
   https://api.talerid.io/mcp
   ```
   *(для тестового контура — `https://staging.id.taler.tirol/mcp`)*
3. Claude перенаправит вас на страницу входа Taler ID — войдите в свой аккаунт.
4. На экране согласия выберите, к чему дать доступ:
   - ✅ Календарь и напоминания
   - ✅ Заметки
   - ✅ Чтение сообщений и контактов
   - ✅ Отправка сообщений контактам
   Можно снять любые галочки — ассистент увидит только разрешённое.
5. Готово. Попросите ассистента: *«Покажи мой календарь на неделю»*.

Другие MCP-совместимые клиенты (ChatGPT, кастомные агенты) подключаются по тому же
адресу — Taler ID использует открытый стандарт Model Context Protocol.

## Безопасность

- **Вы контролируете доступ.** Ассистент получает только те права, которые вы явно
  подтвердили на экране согласия. Отозвать доступ можно в любой момент в настройках
  безопасности Taler ID.
- **Сообщения — только контактам.** Ассистент физически не может написать человеку,
  которого нет в ваших контактах.
- **Пароль не передаётся.** Подключение работает через OAuth: ассистент никогда не
  видит ваш пароль, только временный ключ доступа с ограниченным сроком действия.
- **Никакого доступа к деньгам и документам.** Кошелёк, KYC-документы и настройки
  аккаунта недоступны через AI-подключение.
